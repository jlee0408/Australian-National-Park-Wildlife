# Colour palette

The dashboard uses a restrained, nature-inspired green palette with warm off-white backgrounds and neutral text. The colours are defined primarily in `style.css`; chart-specific colours may also be set in the Vega-Lite JSON files under `specs/`.

## Core interface colours

|Role|Hex value|Use|
|-|-|-|
|Deep forest green|`#244D38`|Hero background, section headings, primary text accents and strong emphasis|
|Mid green|`#47785B`|Interactive accents, checkbox controls and story guide borders|
|Dark leaf green|`#315B45`|Links, labels and secondary emphasis|
|Pale green|`#EDF4ED`|Note backgrounds, navigation chips and highlighted explanatory areas|
|Very pale green|`#F8FBF7`|Light panels and legend backgrounds|
|Page background|`#F3F6F1`|Overall page background|
|White|`#FFFFFF`|Main content cards and chart panels|
|Main text|`#26352C`|Body copy and primary interface text|
|Muted text|`#617064`|Secondary explanations, captions and supporting text|
|Borders|`#E1E8DF`|Card and control outlines|

## Pest assessment colours

The pest explorer uses separate semantic colours for assessment categories. These colours indicate the source's recorded category, not a calculated overall risk score.

|Role|Background|Text|
|-|-|-|
|Higher/severe risk accent|`#FDE4E1`|`#A52F2A`|
|Medium/caution accent|`#FFF0C7`|`#855C00`|
|Lower risk accent|`#E4F2E5`|`#28653B`|
|Neutral/unclassified|`#EDF0ED`|`#536356`|
